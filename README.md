🎮 TanksWinter — танки (зима)
Классическая игра «Танки» в зимнем антураже! Управляйте танком, уничтожайте врагов, собирайте бонусы и наслаждайтесь снежной атмосферой.
Реализована на 7 языках программирования для демонстрации игровой логики и работы с графикой.

🧠 Концепция
TanksWinter — это аркадная игра, где вы управляете танком на заснеженном поле. Ваша задача — уничтожать вражеские танки, которые появляются с краёв карты. Поле покрыто снегом (замедляет движение) и льдом (делает управление скользким). Вы можете прятаться за стенами и использовать бонусы (ускорение, усиленная броня).

✅ Управление — WASD для движения, пробел для стрельбы.

✅ Враги — появляются случайно, движутся к игроку, стреляют.

✅ Зимний ландшафт — снег, лёд, стены создают тактические препятствия.

✅ Бонусы — ускорение, дополнительная жизнь, усиленный снаряд.

✅ Счёт и рекорд — очки за каждого уничтоженного врага, лучший результат сохраняется.

🚀 Как запустить
Каждая версия использует минимальные зависимости. Инструкции по установке и запуску приведены ниже.

Python
bash
pip install keyboard
python tanks_winter.py
C++
bash
# Для Linux требуется ncurses (sudo apt install libncurses-dev)
g++ -std=c++17 tanks_winter.cpp -o tanks_winter -lncurses
./tanks_winter
Java
bash
javac TanksWinter.java && java TanksWinter
C#
bash
dotnet run
Go
bash
go mod init tanks_winter
go get github.com/eiannone/keyboard
go run tanks_winter.go
Rust
bash
cargo new tanks_winter
cd tanks_winter
cargo add termion rand
cargo run
JavaScript (Node.js)
bash
npm install keypress
node tanks_winter.js
